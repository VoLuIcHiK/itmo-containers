# Лабораторная работа №2  
## Проект – графический интерфейс для работы с LLM моделями  

### 1) Можно ли ограничивать ресурсы (например, память или CPU) для сервисов в docker-compose.yml? Если нет, то почему, если да, то как?  
Ответ: Да, можно ограничивать такие ресурсы, как память и процессор, для сервисов в docker-compose.yml. Это поможет предотвратить ситуацию, когда один сервис может использовать слишком много ресурсов и мешать другим. Для ограничения ресурсов используются следующие параметры: cpus (ограничение использования процессора) и memory (ограничение по использованию оперативки). Пример:  

```
services:
  my_service:
    image: myimage:latest
    deploy:
      resources:
        limits:
          cpus: "0.5" # Максимум 50% одного ядра CPU
          memory: 512M # Максимум 512 МБ RAM
```

### 2) Как можно запустить только определенный сервис из docker-compose.yml, не запуская остальные? 
Ответ: Чтобы запустить только конкретный сервис из файла docker-compose.yml, а не все сервисы сразу, нужно воспользоваться командой docker compose up с указанием имени сервиса: docker compose up <имя_сервиса>. Если взять сервис из примера выше, то команда будет выглядеть так: docker compose up my_service.
